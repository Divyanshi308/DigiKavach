# DigiKavach Demo Video Script (3 Minutes)

## PREP (Before Recording)
1. Start backend: `cd backend && python -m app.main`
2. Open web demo in Chrome (Netlify URL or localhost)
3. Open Android emulator with DigiKavach installed
4. Have OBS/Win+G ready to record
5. Hide desktop icons, close notifications

## RECORDING

### Scene 1: Hook (0:00 - 0:10)
- Show title card: "DigiKavach - Digital Armor for Every Indian"
- Voiceover: "India lost 11,300 crore rupees to digital fraud last year. Meet DigiKavach."

- Show 3D globe spinning, animated counters
- Show 4 charts (scam categories, trend, regions, risk)
- Voiceover: "Real-time fraud intelligence across India"
